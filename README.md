# Где прибыль МП — версия 0.8

## Состав
- Сохранённый калькулятор в `index.html`.
- Node.js API: регистрация, вход, профиль, тарифы, платежная история, отмена автопродления, админ-сводка.
- PostgreSQL: пользователи, подписки, платежи, аудит и очередь биллинга.
- Robokassa: платежная ссылка, проверка ResultURL, рекуррентный сценарий.
- Render Blueprint: API + worker + PostgreSQL. Текущий production static site на ветке main не изменяется.

## Локальный запуск
1. `npm install`
2. Создать PostgreSQL базу и выполнить `psql "$DATABASE_URL" -f db/schema.sql`.
3. Скопировать `.env.example` в `.env`, заполнить секреты.
4. `npm start`; отдельным процессом `npm run worker`.

## Перед реальным приёмом денег
- Получить одобрение Robokassa на рекуррентные платежи. По документации эта функция включается только после предварительного согласования.
- В кабинете Robokassa настроить ResultURL: `https://ВАШ-ДОМЕН/api/billing/robokassa/result`; SuccessURL и FailURL на соответствующие маршруты.
- Подключить «Робочеки СМЗ» через «Мой налог» и проверить чек каждого успешного платежа.
- Заполнить APP_URL, MerchantLogin, Пароль №1 и Пароль №2 только в защищённых переменных Render.
- Провести полный тест в тестовом режиме, включая успешный/неуспешный платёж, повторный callback, отмену подписки, продление и возврат.
- Проверить тексты оферты, политику конфиденциальности, согласие на рекуррентные списания и механизм отказа до включения production платежей.

Секреты не хранить в Git и не отправлять в браузер.
