# Подключение SMS для «Где прибыль»

Авторизация работает по номеру телефона: один и тот же одноразовый код используется для регистрации, входа и восстановления доступа. Ссылок для восстановления через почту нет.

## Что уже реализовано

- Запрос одноразового кода через SMSC API.
- Код хранится в базе только в виде SHA-256-хеша с отдельной солью.
- Срок действия кода — 5 минут.
- Повторная отправка на один номер — не чаще одного раза в 60 секунд.
- До 5 попыток ввода одного кода.
- Ограничение запросов по IP.
- Привязка подтверждённого номера к уже существующему аккаунту, чтобы сохранить его данные и подписку.
- Секреты SMS-провайдера хранятся только в переменных окружения API-сервиса Render.

## Что потребуется при подключении

1. Создать аккаунт у SMSC и получить API-ключ в личном кабинете.
2. Убедиться, что на балансе есть средства и разрешена отправка на нужные страны.
3. В Render открыть сервис `gde-pribyl-mp-api` → Environment.
4. Добавить переменную:
   - `SMSC_API_KEY` — API-ключ SMSC.
5. Необязательно добавить:
   - `SMSC_SENDER` — подтверждённое имя отправителя, если SMSC требует его для выбранного маршрута.
6. Сохранить изменения и дождаться перезапуска API.
7. Проверить `https://gde-pribyl-mp-api.onrender.com/health`: поле `smsConfigured` должно быть `true`.

Не передавать API-ключ в переписке и не размещать его в исходном коде.

## Техническая интеграция

API отправки: https://smsc.ru/sys/send.php  
Используется HTTPS POST с параметрами `apikey`, `phones`, `mes`, `fmt=3`, `charset=utf-8`.

Документация SMSC: https://smsc.ru/api/http/send/

До добавления `SMSC_API_KEY` сайт не отправляет реальные сообщения и возвращает понятное сообщение о том, что SMS-провайдер ещё не подключён.
